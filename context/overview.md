# Overview

docu-demo is a Docusaurus 3 site built with React and TypeScript.

Key content areas:
- Docs in `docs/` (intro at `docs/intro.md`).
- Blog posts in `blog/`.
- Custom pages in `src/pages/` (homepage at `src/pages/index.tsx`).
- Shared UI components in `src/components/`.
- Site config in `docusaurus.config.ts` and `sidebars.ts`.

See also: [architecture](architecture.md), [patterns](patterns.md), [context-map](context-map.md).
